Carplay Screen Mirror - Experience a whole new level of simulation! This mod allows you to mirror any desktop window or application (like Spotify, Discord, YouTube, or any browser window) directly onto your truck's GPS, Dashboard, or side mirrors!

==================================================
⚠️ CRITICAL INSTALLATION STEP (MUST READ)
==================================================
Because Steam Workshop does NOT allow .dll plugin files to be uploaded, subscribing to this mod is NOT enough. You MUST download the core plugin file manually.

How to Install:
1. Subscribe to this mod on Steam Workshop.
2. Download the required plugin (CarplayScreenMirror.dll) from the GitHub link below.
3. Place the downloaded .dll file into your Euro Truck Simulator 2 directory:
   Steam/steamapps/common/Euro Truck Simulator 2/bin/win_x64/plugins/
4. Launch the game, press CTRL + F8 and enjoy!

⬇️ DOWNLOAD PLUGIN HERE: github.com/tingoja/CarplayScreenMirror/releases/latest
